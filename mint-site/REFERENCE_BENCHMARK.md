# Original Sweetardio.fun Visual Benchmark

The rendered original landing page establishes a clear visual system that is more specific than a generic neon theme. Its dominant motif is a **single centered glass arcade panel** in front of a visible shop-scene background. The panel is framed by a thin gradient edge, uses one illustrated collection badge, one small status chip, one oversized Pusia wordmark, a short single-paragraph value statement, and a compact set of neon directional controls. The design earns its atmosphere from the spatial relationship between the arcade scene and this panel rather than from repeated borders, card patterns, or informational labels.

| Original Sweetardio.fun rule | Current Cookie Chain divergence | Replacement requirement |
| --- | --- | --- |
| One centered hero panel controls the first impression | The Cookie Chain hero uses an editorial two-column layout unrelated to the original landing scene | Rebuild around a centered glass arcade panel. |
| The shop scene remains visibly legible around the panel | The current background is treated as a near-flat navy surface | Restore a visible scene with a restrained Oxford tint and vignette. |
| Information is concentrated into a chip, short statement, and directional action | The current page still reads as a conventional product landing page | Use the original panel’s compact content density and one primary mint action. |
| Arcade navigation feels like scene interaction, not generic buttons | The current CTA and card grid behave as independent interface blocks | Use a compact, coherent draw selector and low-density mint section that continue the arcade-panel material. |

The canonical Cookie Chain Edition plaque must replace the original collection badge; it should not be treated as a generic corporate logo. Full-quality Cookie Chain artwork should appear in a restrained draw panel below the hero rather than competing with the hero’s central panel.
