# Glass Arcade Panel: Readability Refinement

The current panel establishes a strong reference-faithful composition but still spreads the typography too evenly across its height. The small status chip and kicker compete for attention with the main statement, the description uses a low-contrast lavender against a partially transparent glass material, and the directional mint control is visually lighter than the information it is meant to activate.

| Element | Refinement |
| --- | --- |
| **Panel material** | Increase the opaque Oxford glass layer behind text while keeping the edge gradient and shop scene visible outside the panel. |
| **Status chip** | Use a slightly larger, higher-contrast mono size with less tracking so it is readable without becoming a competing headline. |
| **Wordmark block** | Tighten the gap between the main Sweetardio wordmark and Cookie Chain subtitle, while slightly increasing the subtitle’s line-height. |
| **Description** | Reduce to one short sentence, cap the line width, increase contrast, and use a more generous but intentional leading. |
| **Kicker and control** | Merge the low-value kicker into a brighter, clearly tappable directional mint control; this removes one line of small text and strengthens the action hierarchy. |
| **Vertical rhythm** | Use a consistent 20–28px rhythm between plaque, chip, wordmark, description, and action; reduce the unused lower panel space. |

At desktop and mobile widths, the panel geometry is sound. The refinement should improve the local readability and visual rhythm inside the existing shape, not change its reference-faithful centered composition.

## Validation Notes

At 1365×768, the panel now uses an opaque Oxford glass surface that clearly separates the plaque, status chip, wordmark, description, and mint action from the background. The former lower dead space is reduced, and the mint action has a visible boundary and usable target size. At 390×844, the one-sentence description wraps cleanly with stronger contrast, the status chip remains legible, and the revised spacing keeps the primary hierarchy intact before the draw aisle.
