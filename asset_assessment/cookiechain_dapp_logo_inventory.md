# Cookie Chain Dapp Logo Sticker Inventory

## Authoritative Directory Source

The logo inventory is sourced from the public Cookie Chain ecosystem orbit at <https://invest.cookiechain.wtf/dapps>, reviewed on 2026-08-15. The directory visually lists the live Cookie Chain projects around the core; the current page states that the full directory will return later. Each logo incorporated as a sticker will retain its project name and exact public asset URL in this manifest.

## Canonical Registry Result

The official [Cookie Chain Apps Registry](https://github.com/cookiechain/apps) exposes the exact machine-readable directory behind the ecosystem site at `apps.json`. It contains **22** public app entries with a corresponding public logo asset. These entries are the source of truth for this sticker expansion; the Solana orbit marker and Cookie Chain core/V1–V4 protocol markers visible in the diagram are not dapp-registry entries and are intentionally excluded.

The exact names, tags, source URLs, and live flags are stored in [`cookiechain_dapp_logo_manifest.json`](cookiechain_dapp_logo_manifest.json). This preserves each public source URL and avoids a manually reconstructed or guessed logo list.
